# Week 2 — Loops

## Topic Summary
Loops let a program repeat actions automatically — either a set number of times
or until a condition is met. Combined with conditionals and string methods,
loops allow programs to process input character by character, validate data,
and keep asking until the user gets it right.

## Problem Sets

| File | Problem | Description |
|------|---------|-------------|
| camel.py | camelCase | Prompts user for a camelCase variable name and converts it to snake_case |
| coke.py | Coke Machine | Simulates a vending machine that accepts 25, 10, and 5 cent coins until 50 cents is paid, then returns change |
| twttr.py | Twttr | Prompts user for a word or sentence and outputs it with all vowels removed |
| plates.py | Vanity Plates | Validates a Massachusetts vanity plate against 5 rules and outputs Valid or Invalid |
| nutrition.py | Nutrition | Prompts user for a fruit and returns its FDA calorie count from a preset list |

## Key Concepts
- `while True` loops with `break`
- `for` loops over strings character by character
- `enumerate()` for index and character simultaneously
- Dictionary creation and `.get()` lookup
- String methods: `.isalpha()`, `.isdigit()`, `.isalnum()`, `.isupper()`, `.casefold()`
- Building result strings with `+=`
- Validating user input against multiple rules
- `return True` / `return False` in functions
