# Week 0 — Functions & Variables

## Topic Summary
Functions let you organize reusable blocks of code. Variables store data.
Together they form the foundation of every Python program — taking input,
processing it, and returning output cleanly.

## Problem Sets

| File | Problem | Description |
|------|---------|-------------|
| einstein.py | E = mc² | Takes user's mass input, calculates energy using Einstein's formula with c = 300,000 km/s |
| faces.py | Faces | Converts text emoticons :) and :( into actual emoji faces 🙂 🙁 |
| indoor.py | Indoor Voice | Accepts user input and converts it to lowercase |
| playback.py | Playback Speed | Accepts user input and replaces spaces between words with ... |
| tip.py | Tip Calculator | Takes meal amount and tip percentage as input, calculates tip and total |

## Key Concepts
- Defining and calling functions
- Taking user input with `input()`
- String methods (`.replace()`, `.lower()`)
- Variables and data types
- Basic arithmetic in Python
- `main()` function structure
