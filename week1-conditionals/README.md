# Week 1 — Conditionals

## Topic Summary
Conditionals let a program make decisions using if, elif, and else.
The program checks a condition and runs different code depending on
whether it's True or False. Combined with string methods like .strip()
and .lower(), conditionals handle real user input cleanly.

## Problem Sets

| File | Problem | Description |
|------|---------|-------------|
| bank.py | Bank | Prompts user for a greeting, returns $0, $20, or $100 based on how they say hello |
| deep.py | Deep Thought | Asks the Great Question of Life — returns Yes only if the user knows the answer is 42 |
| extensions.py | Extensions | Takes a filename and identifies its media type based on the file extension |
| interpreter.py | Math Interpreter | Evaluates a math expression entered by the user and returns the result |
| meal.py | Meal Time | Takes a time as input and tells the user if it's breakfast, lunch or dinner time |

## Key Concepts
- `if` / `elif` / `else` statements
- `match` / `case` statements
- String methods: `.lower()`, `.strip()`, `.startswith()`, `.endswith()`
- Handling user input case-insensitively
- Comparing strings and numbers
