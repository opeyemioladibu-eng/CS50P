## Layout

Each week lives in its own folder. Problems with extra files (tests, CSVs, images) have a subfolder; single-file problems sit at the week root.

```text
week0-functions-variables/
week1-conditionals/
week2-loops/
week3-exceptions/
week4-libraries/
week5-unit-testing/
week6-file-io/
  lines/  pizza/  scourgify/  shirt/
week7-regex/
  numb3rs/  watch/  working/  um/  response/
week8-OOP/
  cookie-jar/  seasons-of-love/  shirtificate/
```

Each week folder has a short README with a topic summary and a table of problem sets.
